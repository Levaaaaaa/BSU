# Оценочная функция (ОФ)

Вычисляет энергию связывания комплекса - пары "[[receptor|мишень]]-[[ligand|лиганд]]" - для дальнейшего ранжирования различных конформаций __лиганда__ в [[binding_site|сайте связывания]] на каждом шаге [[docking|конформационного поиска]].

Грубо говоря __ОФ__ показывает, насколько хорошо __лиганд__ подходит __мишени__.

Представляет из себя линейную комбинацию _термов_ - независимых слагаемых, отражающих различные физические взаимодействия.
